# Tea: The official CLI for Gitea

![Gitea](https://img.shields.io/badge/Gitea-609926?logo=gitea&labelColor=gray&logoColor=white)

## 🛠️ Setup

### Install

### Login to a server

```sh
tea login add --name <server_name> --url <server_url> --user <user_name>
```

### Set the default server

```sh
tea login default <server_name>
```
